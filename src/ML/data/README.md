# Synthetic Data Generation

This folder contains Python scripts used to generate synthetic datasets for the ML anomaly-detection pipeline.

Its main responsibilities are:

- generate normal training activity;
- generate independent normal validation activity;
- generate supporting synthetic test data.

The generated logs represent banking-style employee activity such as login, customer access, downloads, account type, IP usage, and timestamps.

The generated CSV files are written to DATA_ML/. This folder contains source code only.
