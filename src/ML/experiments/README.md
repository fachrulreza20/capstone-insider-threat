# Experiment Data Generators

This folder contains Python code that generates experiment-specific synthetic datasets.

Current Experiment 02 scenarios include:

- gradual download increase
- repeated VIP access
- role deviation
- slow behavioural drift
- unusual activity volume during normal working hours

The Python source code lives in this folder.

Generated raw logs, ground truth, predictions, and evaluation outputs are written to:

DATA_ML/experiments/

This keeps experiment code separate from generated research data.
